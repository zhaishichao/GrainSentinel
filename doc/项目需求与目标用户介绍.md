# 粮情哨兵智能体 · 项目需求与目标用户介绍

## 一、项目定位

面向我国粮食仓储与质量安全现状，帮助粮库、储备粮管理单位与粮食质检机构，用「对话」的方式完成
粮情监测、质量检测、虫霉防治、仓储管控、储备轮换与安全预警的一体化粮食安全守护助手。

## 二、核心需求：为什么需要它

当前我国粮食仓储管理普遍面临六类真实痛点：

1. **产后损耗高**：储藏环节损耗约 2%~3%，全国每年因储粮不当造成的损失触目惊心；
2. **粮情监测靠人工**：粮温、水分、虫霉测控点多面广，传统巡检费时费力、异常响应滞后；
3. **储粮风险多、危害大**：发热、结露、霉变、虫害一旦失守，会造成整仓粮食降等报废；
4. **质量检测门槛高**：真菌毒素、重金属等指标专业性强、限量标准繁多，判定依赖经验；
5. **仓储管控不智能**：智能通风、充氮气调、谷物冷却等「科技储粮」技术落地不足、缺决策支撑；
6. **轮换决策靠经验**：宜存/不宜存判定与轮换计划制定缺少量化依据，容易「该换不换、不该换乱换」。

这些痛点的共同点是：**专业门槛高、数据分散、需要跨领域协同**——而这正是「大模型 + 多智能体」
擅长解决的场景。

## 三、目标用户

| 用户 | 典型诉求 |
|------|---------|
| 中央/地方储备粮库保管员、仓储管理员 | 实时监测粮情、研判发热结露、处置虫霉、降低损耗 |
| 粮库 / 粮油集团信息化负责人 | 用智能体统一承载粮情测控、仓储管控与风险预警决策 |
| 粮食质检机构 / 实验室检验员 | 依据国标快速判定质量等级与储存品质 |
| 粮食安全方向的科研与管理人员 | 分析储粮风险、储备轮换策略与质量安全政策 |

## 四、主要解决的粮食安全问题

| 粮食安全问题 | 本项目如何解决 |
|-------------|--------------|
| 粮情监测滞后、异常发现晚 | 结合粮温/水分/气体浓度实时研判发热、结露、霉变风险 |
| 质量指标多、判定难 | 依据国标限量自动判定等级与储存品质（宜存/不宜存） |
| 虫霉防治无依据 | 按密度分级给出熏蒸/气调量化防治方案 |
| 仓储损耗高、管控粗放 | 智能通风/气调/谷物冷却策略，量化损耗降低空间 |
| 储备轮换靠经验 | 基于品质判定给出轮换计划与出入库顺序 |
| 多源风险协同研判难 | 综合评分、分级预警、输出应急处置预案 |

## 五、技术如何支撑这些需求（简要）

- 用**大模型**理解自然语言，降低专业工具的使用门槛；
- 用**多个专职智能体**各司其职（粮情监测 / 质量检测 / 虫霉防治 / 智能仓储 / 储备轮换 / 安全预警），
  由主控智能体自动路由与汇总；
- 用**粮温、水分、毒素限量、虫害密度等数据工具**做量化分析，让结论「有数字、可执行」；
- 通过**可视化面板与流式问答**，让粮情监测过程和分析结果一目了然。

## 六、价值总结

把粮食安全守护从「依赖老师傅经验 + 割裂的工具」变成「自然语言提问 + 一键式协同分析」，
让储粮管理更智能、更量化、更可执行，助力「科技储粮、绿色储粮、智能储粮」落地。
